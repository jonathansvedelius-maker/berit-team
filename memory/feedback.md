# Feedback

> Record both corrections ("don't do X") and validated approaches ("yes, exactly that"). Include **Why:** and **How to apply:** lines so future judgment calls are possible.

## 2026-05-20 — Treat the "100 tips personal agent" post as inspiration, not recipe

**Rule:** Patterns from personal-agent posts (memory, skills, sessions) are useful; autonomous-personal-assistant behaviors (sending messages, VIP tiering, customer outreach) are not.

**Why:** A team agent has a larger blast radius than a personal agent. Autonomous actions on shared state damage trust faster than they save time.

**How to apply:** When evaluating a new pattern, ask "would this work for a team where the agent represents the team to outside humans?" If yes, consider. If it requires the agent to act as a personal proxy, reject.
